# Nmap Practical Labs

This folder contains the practical labs I performed while learning Nmap.

The goal isn't to memorize commands, but to understand how Nmap is actually used during network reconnaissance.

Each lab contains:

- Objective
- Commands Used
- Steps Performed
- Expected Output
- What I Observed
- What I Learned
- Screenshots

---

# Learning Roadmap

We'll cover the following scenarios:

- Host Discovery
- Scan a Single Host
- Scan Multiple Hosts
- Scan Specific Ports
- Scan All Ports
- Service Version Detection
- Operating System Detection
- TCP SYN Scan
- UDP Scan
- Aggressive Scan
- Nmap Scripting Engine (NSE)
- Save Scan Results

---

# Goal

By completing these labs, I'll be able to:

- Discover live hosts on a network.
- Identify open TCP and UDP ports.
- Detect running services.
- Detect service versions.
- Identify the target operating system.
- Understand different scan types.
- Save scan results for future analysis.
- Build a basic reconnaissance workflow used in penetration testing.
